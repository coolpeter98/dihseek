# Dihseek 🐳

DeepSeek, now on Discord!

## Usage

### Prerequisites 

You need [Lune](https://github.com/lune-org/lune) and [Pesde](https://pesde.dev/)

### Setup

Set up the env by renaming .env.luau.example to .env.luau
In the .env.luau file just enter in your deepseek api key and discord bot token, then save the file

Run `pesde install` to install the required dependencies, then in the root of the directory, run `lune run src/init.luau`

The bot should be up and running! You may need to refresh Discord for the `/chat` slash command to appear.

### Stance on AI

I personally do not want purely AI code in this repository as I do not want to bother reviewing code someone else didn't even bother to write.
Asking for general help from AI is fine, though
